# Projets d'Analyse de Données & Biostatistiques

Ce dépôt réunit mes travaux pratiques d'analyse de données, de biostatistique et de programmation réalisés avec Python et R sur Google Colab.

---

## 📌 Contenu du Répertoire:

### 1. 🧬 TP_Breast_Cancer_Analysis.ipynb:
* Langage : Python (Pandas, Matplotlib, Seaborn)
* Sujet : Analyse exploratoire des données (EDA) et visualisation d'un jeu de données médicales sur le cancer du sein.

### 2. 📊 TP_R_Data_Analysis.ipynb:
* Langage : R
* Sujet : Traitement de données et analyses statistiques appliquées avec le langage R.

### 3. 🦠 TP_COVID19_Data_Analysis.ipynb:
* Langage : Python
* Sujet : Application des notions fondamentales de Python (variables, fonctions, conditions, boucles, structures de données) sur des statistiques du COVID-19.

---

## 🛠️ Compétences & Outils:
* Langages : Python, R
* Outils : Google Colab, Jupyter Notebook, GitHub
* Domaines : Biostatistique, Analyse de données, Visualisation
